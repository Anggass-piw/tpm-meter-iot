TPM Meter

Pantau pembacaan minyak goreng, tren suhu, dan status pengiriman dari perangkat ESP32.

Menghubungkan API…
Penting: nilai demo bersifat sintetis. Estimasi TPM belum divalidasi terhadap alat ukur acuan dan bukan penilaian keamanan pangan.
Offline: hanya kerangka dashboard yang tersedia. Data API tidak disimpan untuk penggunaan offline; nilai yang terlihat bukan data live. Sambungkan kembali untuk memuat pembacaan terbaru.
Petunjuk pemasangan dan dukungan perangkat

Pasang hanya dari koneksi aman HTTPS; saat pengembangan, localhost juga diizinkan. Tombol “Pasang aplikasi” muncul bila browser mendukung pemasangan langsung.

  • Android / desktop: buka dashboard di Chrome/Edge melalui HTTPS atau localhost, lalu pilih tombol Pasang aplikasi (atau “Install app” dari menu browser).
  • iPhone / iPad: buka dengan Safari melalui HTTPS, tekan Bagikan, lalu “Tambahkan ke Layar Utama”. iOS tidak menampilkan prompt pemasangan web yang sama seperti Chrome.
  • Dashboard tetap memerlukan API untuk pembacaan. Mode offline hanya menyediakan shell UI, bukan riwayat atau telemetri yang tersimpan.
